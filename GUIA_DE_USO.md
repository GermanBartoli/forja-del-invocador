# Guía de uso de Forja del Invocador

1. Pulsá **Explorar objetos** para ir al arsenal y buscá por nombre o estadística.
2. Abrí una ficha para recorrer componentes, costos y mejoras; guardá tus favoritos en este navegador.
3. Entrá en Entrenamiento y elegí ícono, receta o nombre para jugar una partida de diez rondas.

4. Abrí **La Grieta**, elegí la región y buscá el Riot ID completo. Desde una partida podés ver ambos equipos, objetos, oro y cronología. «Cargar más partidas» amplía la muestra de rendimiento.
5. Consultá la rotación gratuita, las ligas, las divisiones, Clash, los desafíos y el estado del servidor. **Atlas** y **Explorar un perfil de ejemplo** están disponibles incluso sin conexión a la API autenticada.
